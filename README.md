# Clase de español: interactive activities

Self-contained HTML pages. No build step and no other files needed.

| File | What it is |
|---|---|
| `index.html` | Home page with links to every activity |
| `calendario.html` | Calendar routine board, planet code, and Mi calendario assignment (teacher audio built in) |
| `que-hora-es.html` | Telling time 1: analog clocks, whole hours |
| `que-hora-es-2.html` | Telling time 2: digital clocks, minutes, mañana / tarde / noche, plus reference tab |
| `cuanto-cuesta.html` | ¿Cuánto cuesta? La tienda: build a shop, buy and sell, receipt |
| `numeros-21-50.html` | Los números 21–50: patterns, practice, Number Challenge, 21–50 chart |
| `cuantos-hay.html` | Uno y más de uno + ¿Cuántos hay?: singular/plural and counting |
| `que-hay-en-el-oceano.html` | ¿Qué hay en el océano?: explore the ocean, hay, un/una, plurals |
| `las-estaciones.html` | Las cuatro estaciones: learn, sort by season, challenge |
| `vamos-de-picnic.html` | Vamos de picnic: Quiero…, por favor, mi canasta y tu canasta |
| `conversaciones-repaso.html` | Conversaciones en español: Quarter 2 review (full 12 or quick 6) |
| `img/` | Optional pictures for the ocean and seasons lessons (see img/README.txt) |

## Publish with GitHub Pages

1. Upload all files to the root of your repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. Your site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Linking straight to one tab

Add the tab name after `#`:

- `calendario.html#calendario`, `#codigo`, `#tarea`
- `que-hora-es.html#presentacion`, `#practica`, `#juego`
- `que-hora-es-2.html#aprender`, `#practicar`, `#jugar`, `#mas`
- `numeros-21-50.html#aprender`, `#practicar`, `#jugar`, `#tabla`
- `cuantos-hay.html#aprender`, `#practicar`, `#jugar`, `#ayuda`
- `que-hay-en-el-oceano.html#explorar`, `#practicar`, `#jugar`, `#vocabulario`
- `las-estaciones.html#aprender`, `#clasificar`, `#jugar`, `#ayuda`
- `vamos-de-picnic.html#canasta`, `#practicar`, `#jugar`, `#ayuda`
- `conversaciones-repaso.html#practicar`, `#jugar`, `#ayuda`

## Results

Each challenge ends with a Copy Results button. Students paste the summary (name, date, questions completed, correct on the first try, status) into Teams. No screenshots and no percentage grade.
