# Clase de español: interactive activities

Self-contained HTML pages. No build step and no other files needed.

| File | What it is |
|---|---|
| `index.html` | Home page with links to every activity |
| `calendario.html` | Calendar routine board, planet code, and Mi calendario assignment (teacher audio built in) |
| `que-hora-es.html` | Telling time 1: analog clocks, whole hours |
| `que-hora-es-2.html` | Telling time 2: digital clocks, minutes, mañana / tarde / noche, plus reference tab |

## Publish with GitHub Pages

1. Upload all files to the root of your repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. Your site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Linking straight to one tab

Add the tab name after `#`:

- `calendario.html#calendario`, `#codigo`, `#tarea`
- `que-hora-es.html#presentacion`, `#practica`, `#juego`
- `que-hora-es-2.html#aprender`, `#practicar`, `#jugar`, `#mas`
